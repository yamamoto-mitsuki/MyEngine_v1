## このファイルについて
- モデルファイルの読み込み（assimp）と、その中の階層構造・アニメーションに関する作業を書く。
- マテリアルの中身（色・PBRの値・切り抜き）は `Material.md`、Entityの階層は `Editor.md`。
- 話題ごとに1ファイルで、**終わっても消さずに更新し続ける**。終わったStepで消してよいのは写経用のコードだけ（コミットしてから）。「なぜ」は「決めたこと」の表へ移す。
