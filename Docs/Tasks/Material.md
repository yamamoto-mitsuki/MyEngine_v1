# マテリアル系の作業

## このファイルについて
- 物の見た目の設定（色、UV、光沢、金属感、切り抜きなど）に関する作業を書く。
- 話題ごとに1ファイルで、**終わっても消さずに更新し続ける**。終わったStepで消してよいのは写経用のコードだけ（コミットしてから）。「なぜ」は「決めたこと」の表へ移す。
- 各Stepの確認は **エンジンのビルド → ゲームのビルド → 実行して「確認すること」** の3段階で行う。
